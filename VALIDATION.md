# Проверка прототипа 0.1.0

Дата: 2 ноября 2026 года. Среда проверки: Windows, Python 3, Chrome через Playwright. Системные настройки Windows не изменялись.

## Сервер

Команда: `python3 -B -m unittest discover -s tests -v`.

**7 тестов пройдены.** Проверены:

1. Недоступность данных до входа, проверка Host/Origin/CSRF, прекращение действия сеанса после выхода.
2. Запрет команд для точки без связи; блокировка/возврат штатного режима; сохранение изменений в SQLite.
3. Принятие предупреждения с комментарием без снятия неисправности.
4. Создание гостя, отказ при повторной карте и прошедшем сроке; запрет прохода по истёкшему пропуску.
5. Экспорт только выбранных событий, защита CSV от формул, недоступность исходников и базы через HTTP.
6. Временное ограничение входа после пяти неудачных попыток.
7. Добавление демонстрационного события и согласованное изменение счётчика присутствия.

При проверке выявлена и исправлена утечка соединений SQLite. Соединения теперь закрываются явно после каждой транзакции.

## Интерфейс

Через настоящий локальный сервер в Chrome проверены вход, обе темы, открытие карточки точки, блокировка и восстановление режима, принятие предупреждения, создание гостя, поиск сотрудников, фильтрация журнала, сохранение CSV, разделы мониторинга/отчётов/параметров, проверка доступа и блокировка сеанса. JavaScript-ошибок не обнаружено.

После исправления размеров контейнера плана проверены 1280×720, 1440×900, 1920×1080 и 2560×1440 при масштабе браузера 100%. Основной экран не выходит за размер окна; все пять маркеров плана находятся в видимой области. Длинные списки прокручиваются внутри своих панелей.

Дополнительно проверены сенсорный размер элементов, предупреждение о несохранённом гостевом пропуске, отображение потери сервера и автоматическое восстановление связи. Скриншоты тёмной и светлой темы получены из работающего приложения.

## Границы проверки

Не проверялись исполнением: Ubuntu/apt/systemd/snap, WPE WebKit, загрузка после перезапуска ОС, видеодрайвер, переключение раскладки, сенсорное устройство, DPI 125/150%, блокировка виртуальных консолей, откат ограничений, реальный контроллер или считыватель.

В этой среде нет доступной Ubuntu для интеграционного запуска. `bash scripts/check.sh` проверяет синтаксис всех shell-файлов перед установкой и запускает тесты. Не следует считать подготовленный архив проверенным установочным образом ОС или промышленной СКУД.

## Установщик и обновление через Git

Добавлены `install.sh`, `update.sh` и инструкция `INSTALL.md`. **8 дополнительных тестов пройдены в GNU Bash 5.2.37 (Git for Windows)**: синтаксис всех скриптов, справка, отказ при неизвестном параметре, получение обновления с переходом к установщику, отказ при локальных изменениях, отсутствии tracking-ветки и неудачном pull, установка локальных файлов без Git.

Git и sudo в этих сценариях заменены тестовыми командами в изолированных временных папках. Тесты проверяют выбор действий и обработку ошибок, но не выполняют настоящую установку системных пакетов. Под root пять сценариев обновления пропускаются, поскольку `update.sh` намеренно запрещает запуск Git от root. Для полной проверки запускайте `bash install.sh --check` обычным пользователем; при установке под sudo оставшиеся проверки выполняются автоматически.

## Переход на Ubuntu Server 26.04 LTS

Основная целевая версия изменена на 26.04 LTS, совместимость с 24.04 LTS сохранена. Проверка ОС вынесена в `scripts/platform.sh` и применяется общим установщиком, установщиком сервера и установщиком киоска. Добавлен тест допуска Ubuntu 26.04/24.04 и отказа для 26.10, 22.04, другой ОС и отсутствующей версии.

После изменения выполнен полный набор: **16 тестов прошли** (9 проверок установщика и 7 серверных). Скрипты разобраны Bash без синтаксических ошибок. Реальная установка Ubuntu 26.04, графика VirtualBox и запуск WPE по-прежнему требуют проверки на пользовательском стенде; проверки версии и документации не заменяют такого запуска.

## Допуск Ubuntu 26.10

После получения снимка пользовательского стенда уточнена фактическая версия ОС: 26.10. Она добавлена в общий список допустимых версий. Тест платформы теперь ожидает успех для 26.10, 26.04 и 24.04. Это устраняет остановку по версии, но не подтверждает запуск графики на 26.10: проверка WPE/Frame остаётся за реальным стендом.
